# Java OOP Practice

This repository contains Java programs created to practice and understand the core concepts of **Object-Oriented Programming (OOP)**. It includes 11 practice questions covering encapsulation, inheritance, polymorphism, method overriding, abstraction, and a comprehensive Employee Management System.

## 📚 Topics Covered

- **Encapsulation** — Private fields, getters, setters, and data protection.
- **Inheritance** — Reusing properties and methods through class hierarchies.
- **Polymorphism** — Method overriding and runtime polymorphism.
- **Abstraction** — Abstract classes and implementation of abstract methods.
- **OOP Project** — Employee Management System using inheritance and polymorphism.

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/vimal-kumar-3/Java-OOP-Practice.git
   ```

2. Open the project in IntelliJ IDEA or another Java IDE.
3. Open the required question folder.
4. Run its main class.

You can also compile and run Java files from the terminal. If a question contains multiple classes, compile the required source files together.
